Gemma 4 12B 설치 & 사용 가이드

구글이 이번 달 공개한 최신 멀티모달(텍스트·이미지·오디오·비디오) 오픈 모델. 16GB VRAM/통합 메모리만 있으면 노트북에서도 로컬로 돌아갑니다.

1 Gemma 4 12B란?

Gemma 4 12B는 2026년 6월 3일 공개된 Gemma 4 제품군의 다섯 번째 변형입니다 (4월 2일 E2B·E4B·26B MoE·31B dense에 이어 출시). 비전·오디오용 별도 인코더를 두지 않는 인코더리스(encoder-free) 통합 멀티모달 아키텍처를 채택해, 원본 이미지 패치와 오디오 파형을 가벼운 선형 계층으로 LLM 임베딩 공간에 직접 투영합니다. 그 결과 텍스트·이미지·오디오·비디오를 한 번의 패스로 처리하면서 지연 시간을 줄였습니다.

3 가장 쉬운 방법 — Ollama

1) Ollama 설치

# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows는 https://ollama.com/download 에서 설치파일 다운로드

2) 모델 받기 & 실행

# 모델 다운로드
ollama pull gemma4:12b

# 대화형 실행
ollama run gemma4:12b

3) API로 호출 (OpenAI 호환)

curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
        "model": "gemma4:12b",
        "messages": [{"role": "user", "content": "안녕! 자기소개 해줘"}]
      }'
다른 크기 변형도 같은 방식으로 사용 가능: ollama run gemma4:4b ollama run gemma4:12b ollama run gemma4:27b gemma4:12b-mlx (Apple)

4 Hugging Face Transformers (Python)

1) 설치 & 모델 접근

pip install -U transformers accelerate torch
⚠️ google/gemma-4-12B-it 모델은 Hugging Face에서 라이선스 동의(gated)가 필요합니다. 모델 페이지에서 약관에 동의한 뒤 huggingface-cli login 으로 토큰 로그인하세요.

2) pipeline로 간단히 사용

from transformers import pipeline

MODEL_ID = "google/gemma-4-12B-it"
pipe = pipeline(
    task="any-to-any",   # 멀티모달 생성
    model=MODEL_ID,
    device_map="auto",
    dtype="auto",
)

messages = [{"role": "user", "content": "파이썬으로 피보나치 함수를 작성해줘"}]
out = pipe(messages, max_new_tokens=512)
print(out)

3) 모델 직접 로드 (세밀한 제어)

import torch
from transformers import AutoProcessor, AutoModelForCausalLM

MODEL_ID = "google/gemma-4-12B-it"
processor = AutoProcessor.from_pretrained(MODEL_ID)
model = AutoModelForCausalLM.from_pretrained(
    MODEL_ID,
    torch_dtype=torch.bfloat16,
    device_map="auto",
)
💡 추론(thinking) 모드: 시스템 프롬프트 맨 앞에 <|think|> 토큰을 넣으면 단계적 추론이 활성화됩니다. 역할은 표준 system / user / assistant 를 사용합니다.

6 활용 시나리오 & 팁

  • 로컬 프라이빗 에이전트 — 데이터를 외부로 보내지 않고 노트북에서 멀티모달 어시스턴트 구동
  • 오디오 네이티브 처리 — 별도 STT 없이 오디오를 직접 입력받는 첫 중형 모델
  • 긴 문서 분석 — 256K 컨텍스트로 대용량 문서/코드베이스 처리
  • 다국어 — 140개 언어 지원, 한국어 포함
성능이 부족하면 gemma4:4b로 낮추고, 정확도가 중요하면 gemma4:27b 또는 BF16 풀 정밀도를 사용하세요.
