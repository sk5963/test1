1. Gemma 4 12B란?

Gemma 4 12B는 구글 DeepMind이 2026년 6월 3일 공개한 120억(12B) 파라미터 규모의 오픈웨이트 모델입니다. Apache 2.0 라이선스로 배포되어 상업적 이용이 자유롭습니다.

가장 큰 특징은 인코더가 없는(encoder-free) 통합 멀티모달 아키텍처입니다. 기존처럼 별도의 비전·오디오 인코더를 거치지 않고 텍스트·이미지·오디오 데이터를 LLM 백본에 직접 입력하여 멀티모달 지연시간(latency)을 크게 줄였습니다. Gemma 계열 중 중간 크기 모델로는 처음으로 오디오를 네이티브로 입력받을 수 있습니다.

4. Ollama로 설치 (가장 쉬움)

1

Ollama 설치

macOS / Linux
curl -fsSL https://ollama.ai/install.sh | sh

Windows는 ollama.com/download에서 설치 프로그램을 받으세요.

2

모델 다운로드

# 기본 양자화(Q4_K_M, 약 7GB) 다운로드
ollama pull gemma4:12b
3

바로 대화 시작

ollama run gemma4:12b

프롬프트가 뜨면 바로 질문을 입력할 수 있습니다. 종료는 /bye.

5. 기본 사용법

텍스트 대화

ollama run gemma4:12b "양자컴퓨팅을 초등학생도 이해하게 설명해줘"

이미지 입력 (멀티모달)

ollama run gemma4:12b "이 스크린샷에 뭐가 보여?" --image ./screenshot.png
참고: Gemma 4 12B는 오디오 입력도 네이티브로 지원합니다. 다만 Ollama 등 런타임별로 오디오 입력 지원 시점이 다를 수 있으니, 최신 버전으로 업데이트한 뒤 사용하세요.

6. API로 호출하기

Ollama는 OpenAI 호환 엔드포인트를 http://localhost:11434에 제공합니다.

curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemma4:12b",
    "messages": [
      {"role": "user", "content": "안녕! 한 문장으로 자기소개 해줘."}
    ]
  }'

Python (OpenAI SDK 호환)

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama",  # 임의 값
)

resp = client.chat.completions.create(
    model="gemma4:12b",
    messages=[{"role": "user", "content": "파이썬으로 피보나치 함수 짜줘"}],
)
print(resp.choices[0].message.content)

7. Python / Transformers로 직접 실행

Hugging Face 가중치를 직접 쓰고 싶다면 Transformers를 사용합니다.

pip install -U transformers accelerate torch
from transformers import pipeline
import torch

pipe = pipeline(
    "text-generation",
    model="google/gemma-4-12b-it",
    torch_dtype=torch.bfloat16,
    device_map="auto",
)

messages = [{"role": "user", "content": "Gemma 4의 장점을 3가지로 요약해줘"}]
out = pipe(messages, max_new_tokens=512)
print(out[0]["generated_text"][-1]["content"])
Tip: Hugging Face에서 게이트된 모델일 경우 huggingface-cli login으로 토큰 인증 후 다운로드하세요. 모델 ID는 배포 채널에 따라 다를 수 있으니 공식 모델 카드를 확인하세요.

8. 양자화 옵션

메모리와 품질의 균형에 따라 양자화 레벨을 고르세요.

양자화특징권장 메모리
Q4_0더 작고 빠름, 품질 약간 하락~10 GB
Q4_K_M 기본값16GB 환경에 최적 균형12–16 GB
Q5_K_M더 높은 품질16–20 GB
Q8_0거의 풀 품질24 GB+
 
# 예: 고품질 Q8 버전 받기
ollama pull gemma4:12b-q8_0

구글은 토큰을 한 번에 여러 개 예측하는 MTP(Multi-Token Prediction) 변형도 제공합니다. 품질 손실을 최소화하면서 약 5–15% 빠른 추론을 얻을 수 있습니다.

9. FAQ & 팁

Q. 모델이 너무 느려요.

GPU 가속이 켜져 있는지 확인하고(ollama ps), VRAM이 부족하면 Q4_0 등 더 낮은 양자화로 바꾸세요. CPU만으로 돌리면 매우 느립니다.

Q. 다운로드한 모델 목록/삭제는?

ollama list          # 설치된 모델 보기
ollama rm gemma4:12b # 삭제

Q. 4B 같은 더 작은 버전도 있나요?

네, gemma4:4b는 6GB VRAM 정도에서 동작합니다. 가벼운 작업엔 충분합니다.

요약: ollama pull gemma4:12b → ollama run gemma4:12b 두 줄이면 16GB 노트북에서 멀티모달 로컬 AI를 바로 쓸 수 있습니다.
