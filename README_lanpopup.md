# LAN 팝업 메신저 (lanpopup.py)

같은 네트워크(같은 공유기/사내망) 안에서 한쪽이 메시지를 보내면,
받는 쪽 PC 화면에 **팝업 창**이 떠서 알려주는 초간단 도구입니다.

- 외부 라이브러리 설치 **불필요** (Python 표준 라이브러리만 사용)
- Windows 기준 (Python 설치 시 tkinter 기본 포함)

## 준비물
- 양쪽 PC에 Python 3 설치
- 두 PC가 **같은 네트워크**에 연결

## 사용법

### 1) 받는 쪽 (팝업을 띄울 PC)
```cmd
python lanpopup.py recv
```
실행하면 아래처럼 자기 IP가 표시됩니다. 이 IP를 보내는 사람에게 알려주세요.
```
[수신 대기 중] 내 IP: 192.168.0.10  포트: 50505
```

### 2) 보내는 쪽
```cmd
python lanpopup.py send 192.168.0.10 "점심 먹으러 갈까요?"
```
`192.168.0.10` 자리에 받는 쪽 PC의 IP를 넣으면, 받는 쪽 화면에 팝업이 뜹니다.

## 옵션
- 포트를 바꾸려면 양쪽 모두 `--port` 를 동일하게 지정하세요.
  ```cmd
  python lanpopup.py --port 60000 recv
  python lanpopup.py --port 60000 send 192.168.0.10 "안녕"
  ```

## 잘 안 될 때
- **팝업이 안 떠요** → 받는 쪽 Windows 방화벽에서 Python의 해당 포트(기본 50505) 인바운드를 허용하세요.
  처음 `recv` 실행 시 방화벽 허용 창이 뜨면 "허용"을 누르면 됩니다.
- **연결이 안 돼요** → 두 PC가 정말 같은 네트워크인지, IP가 맞는지 확인하세요.
  받는 쪽에서 `ipconfig` 로 IPv4 주소를 다시 확인할 수 있습니다.
- **여러 명에게서 받기** → 받는 쪽은 그대로 두면 여러 사람의 메시지를 계속 팝업으로 보여줍니다.

## 한계 (초간단 버전이라)
- 암호화/인증 없음 → 신뢰할 수 있는 사내망/가정망에서만 사용하세요.
- 메시지 저장 기능 없음 (팝업만 표시).
