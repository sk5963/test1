# LAN 채팅 (lanpopup.py)

같은 네트워크(같은 공유기/사내망) 안에서 동작하는 초간단 채팅 프로그램입니다.
**모든 PC가 서버 능력을 내장**하고 있어서, 따로 서버 PC를 켜둘 필요가 없습니다.

- 네트워크에 호스트가 있으면 → 자동으로 찾아서 **클라이언트로 접속**
- 호스트가 없으면 → 내가 **스스로 호스트**가 됨
- 호스트가 꺼지면 → 남은 PC 중 하나가 **자동으로 새 호스트**가 됨 (failover)

외부 라이브러리 설치 없이 Python 표준 라이브러리(socket / threading / tkinter / json)만 사용합니다.

## 기능
- 닉네임(보낸/받는 사람) 표시
- **접속자 목록** 실시간 표시
- **전체 채팅 / 1:1(DM) / 그룹(방) 채팅**
- 새 메시지가 오면 창·작업표시줄 **깜빡임 + 알림음**
- **대화 기록을 로컬 파일에 저장** → 다시 열면 이전 대화가 보임
  - 저장 위치: `lanpopup_history/<내닉네임>/<대화>.jsonl`
- **서버 없이 자동 호스트 선출 + 장애 복구(failover)**

## 준비물
- 모든 PC에 Python 3 설치 (Windows는 tkinter 기본 포함)
- 모든 PC가 같은 네트워크에 연결

## 사용법 (가장 간단 — 권장)
각 PC에서 그냥 이렇게만 실행하면 됩니다:
```cmd
python lanpopup.py join 홍길동
```
- 닉네임을 생략하면 실행 후 입력창이 뜹니다.
- 처음 실행한 PC가 자동으로 호스트가 되고, 이후 실행하는 PC들은 그 호스트에 접속합니다.
- 호스트 PC를 끄면 남은 PC 중 하나가 자동으로 호스트를 넘겨받고, 나머지는 거기에 다시 붙습니다.
  (재접속 시 참여 중이던 그룹방에도 자동으로 다시 들어갑니다.)

## 수동 모드 (원하면)
고정 서버를 두고 싶을 때:
```cmd
python lanpopup.py server                  :: 이 PC를 고정 호스트로
python lanpopup.py client 192.168.0.10 홍길동 :: 특정 서버로 직접 접속
```

## 채팅 창 사용법
- **왼쪽 목록**: `전체 (모두)`, 참여 중인 그룹(👥), 접속자/대화 상대(👤)
  - 새 메시지가 온 대화 앞에는 `●` 표시가 붙습니다.
- **1:1 대화** 버튼: 상대 닉네임을 입력해 DM 시작
- **그룹 참여/만들기** 버튼: 방 이름 입력 (없으면 새로 생성, 있으면 참여)
- **그룹 나가기** 버튼: 현재 보고 있는 그룹에서 나가기
- 아래 입력칸에 글 쓰고 **Enter** 또는 **보내기**

## 옵션
- 포트 변경 시 모든 PC가 동일하게 맞춰야 합니다 (채팅 포트 N, 자동 탐색 포트 N+1 사용):
  ```cmd
  python lanpopup.py --port 60000 join 홍길동
  ```

## 동작 방식 (자동 호스트)
- 시작하면 UDP 브로드캐스트로 "호스트 있나요?"(포트 = 채팅포트+1)를 보냅니다.
- 응답이 오면 그 IP로 접속하고, 응답이 없으면 채팅 포트를 잡아 스스로 호스트가 됩니다.
- 포트 잡기에 실패하면(다른 PC가 동시에 호스트가 됨) 다시 탐색해서 그 호스트로 접속합니다.
- 호스트가 사라지면 연결이 끊기고, 같은 과정을 반복해 **새 호스트를 자동 선출**합니다.

## 잘 안 될 때
- **접속이 안 돼요 / 서로 못 찾아요** → Windows 방화벽에서 Python의 해당 포트
  (기본 50505 TCP + 50506 UDP) 인바운드를 허용하세요. 처음 실행 시 방화벽 허용 창이 뜨면 "허용".
- **닉네임 중복** → 같은 닉네임으로 접속하면 자동으로 `이름_2` 처럼 번호가 붙습니다.

## 한계 (초간단 버전이라)
- 암호화/인증 없음 → 신뢰할 수 있는 사내망/가정망에서만 사용하세요.
- 호스트가 바뀌면 서버측 상태(접속자/방)는 새로 시작됩니다. 각 PC의 대화 기록은 로컬에 남아 있고,
  참여 중이던 그룹방은 재접속 시 자동으로 다시 들어갑니다.
- 호스트 교체 중 잠깐(보통 수 초) 메시지 전송이 멈출 수 있습니다.
- 두 PC가 거의 동시에 시작하면 드물게 호스트가 둘 생길 수 있습니다 (각자 따로 보임).
  이때는 한쪽을 다시 시작하면 됩니다.
- 오프라인 사용자에게 보낸 DM은 전달되지 않습니다 (오프라인 메시지 보관 없음).
