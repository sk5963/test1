# LAN 채팅 (lanpopup.py)

같은 네트워크(같은 공유기/사내망) 안에서 동작하는 초간단 채팅 프로그램입니다.
**중앙 서버 1대 + 클라이언트(채팅 창)** 구조이며, 외부 라이브러리 설치 없이
Python 표준 라이브러리(socket / threading / tkinter / json)만 사용합니다.

## 기능
- 닉네임(보낸/받는 사람) 표시
- **서버 접속자 목록** 실시간 표시
- **전체 채팅 / 1:1(DM) / 그룹(방) 채팅**
- 새 메시지가 오면 창·작업표시줄 **깜빡임 + 알림음**
- **대화 기록을 로컬 파일에 저장** → 다시 열면 이전 대화가 보임
  - 저장 위치: `lanpopup_history/<내닉네임>/<대화>.jsonl`

## 준비물
- 모든 PC에 Python 3 설치 (Windows는 tkinter 기본 포함)
- 모든 PC가 같은 네트워크에 연결

## 사용법

### 1) 서버 실행 (한 PC에서 한 번만)
모두가 접속할 PC에서:
```cmd
python lanpopup.py server
```
실행하면 서버 IP가 표시됩니다. 이 IP를 참여자들에게 알려주세요.
```
[서버 시작] IP: 192.168.0.10  포트: 50505
```

### 2) 클라이언트 실행 (참여하는 각 PC에서)
```cmd
python lanpopup.py client 192.168.0.10 홍길동
```
- 첫 번째 인자: **서버 IP**
- 두 번째 인자: **닉네임** (생략하면 실행 후 입력창이 뜸)

> 서버를 실행한 PC에서도 클라이언트로 접속할 수 있습니다 (이 경우 IP는 `127.0.0.1` 또는 자기 IP).

## 채팅 창 사용법
- **왼쪽 목록**: `전체 (모두)`, 참여 중인 그룹(👥), 접속자/대화 상대(👤)
  - 새 메시지가 온 대화 앞에는 `●` 표시가 붙습니다.
- **1:1 대화** 버튼: 상대 닉네임을 입력해 DM 시작
- **그룹 참여/만들기** 버튼: 방 이름 입력 (없으면 새로 생성, 있으면 참여)
- **그룹 나가기** 버튼: 현재 보고 있는 그룹에서 나가기
- 아래 입력칸에 글 쓰고 **Enter** 또는 **보내기**

## 옵션
- 포트 변경 시 서버·클라이언트 모두 동일하게:
  ```cmd
  python lanpopup.py --port 60000 server
  python lanpopup.py --port 60000 client 192.168.0.10 홍길동
  ```

## 잘 안 될 때
- **접속이 안 돼요** → 서버 PC의 Windows 방화벽에서 해당 포트(기본 50505) 인바운드를 허용하세요.
  서버를 처음 실행할 때 방화벽 허용 창이 뜨면 "허용"을 누르면 됩니다.
- **IP 확인** → 서버 PC에서 `ipconfig` 의 IPv4 주소를 확인하세요.
- **닉네임 중복** → 같은 닉네임으로 접속하면 자동으로 `이름_2` 처럼 번호가 붙습니다.

## 한계 (초간단 버전이라)
- 암호화/인증 없음 → 신뢰할 수 있는 사내망/가정망에서만 사용하세요.
- 서버가 꺼지면 모두 연결이 끊깁니다 (대화 기록은 각 PC에 남아 있음).
- 오프라인 사용자에게 보낸 DM은 전달되지 않습니다 (오프라인 메시지 보관 없음).
