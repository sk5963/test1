# 전체 리뷰 2회 완료 기록

날짜: 2026-10-05 / 최종 데모: 0.2.1

전체 리뷰는 요구사항, 각 기능 모듈, 실행 경계, 자료 보존, 오류 복구, UI, 설치 스크립트, 문서·예시 결과 및 업로드 대상으로 수행했다. 2차는 1차 문제를 수정한 상태에서 다시 점검했다. 중간에 추가된 Parquet와 전체 측정값 Excel 요구도 최종 검증에 포함했다.

## 1차 — 기능·운영 흐름 점검과 수정

| 발견 사항 | 영향 | 수정 |
| --- | --- | --- |
| 성공 이력만 보고 단계·전체 처리를 건너뜀 | 결과 파일이 삭제·변조돼도 완료로 표시 | 단계 파일 목록·크기·해시 저장 및 재검증; 자동 처리는 새 실행 건으로 복구 |
| 선행 결과 검증이 일부 입력만 대상으로 수행됨 | 통계 파일 손상이 Report·업로드에 전파 | 선행 성공 단계 전체 파일 해시 검사 |
| 한 정리 건의 JSON·파일 오류가 전체 정리를 중단함 | 다른 정상 실행도 정리 지연 | 실행별 보류 기록과 정상 실행 계속 처리 |
| 정리 시 원본 존재·해시를 확인하지 않음 | 재생성 원본이 없는데 중간 파일 삭제 가능 | 원본 없거나 변경된 건은 중간 데이터 보존 |
| 독립 FTP CLI가 공통 잠금·상태 기록을 우회 | 수동·자동 전송 충돌 및 상태 불일치 | Controller와 같은 잠금·선행 검증·업로드 이력 사용 |
| FTP 서버·원본 폴더가 바뀌어도 같은 로컬 상대 경로 사용 | 같은 이름의 다른 자료가 원본 보관 파일 덮어씀 | 원본 출처별 raw 폴더 분리 |
| 잘못된 기존 설정이 상태 조회·설정 저장·중지도 막음 | UI나 서버 복구 어려움 | 설정 오류 상태 표시, 새 설정 검증·저장, 독립 중지 요청 |
| 자동 실행 중 잘못된 설정이 서비스 자체를 종료함 | 서버 상시 처리 중단 | 오류 기록 후 다음 주기 재확인; 정상 중지 가능 |
| 맵 출력이 좌표 최소·최대를 셀마다 재계산 | 셀 수 증가 시 불필요한 계산 증가 | 좌표 범위 한 번 계산 |
| Electron 명령 결과 배열·서비스 시작 오류 처리 | 장시간 수동 로그 메모리 및 파일 핸들 누수 가능 | 최근 메시지 수 제한·로그 버퍼 제한·핸들 finally 해제 |

통계의 2회 읽기 사이 입력 변경 감지, FTP 완료 목록 크기 검사, 모의 전송 임시 파일 후 교체, 잘못된 변환 입력 검증 순서도 보완했다. 원본 vendor 소스의 바이트와 해시는 보존했다.

## 2차 — 수정본·추가 요청·실행 결과 검증

- 기본 Parquet · ZSTD, 기존 CSV 선택, 포맷 변경 시 새 실행 건을 검증했다.
- CSV/Parquet의 실제 측정값·원본 번호·열 식별자·수율·히스토그램·맵이 일치함을 확인했다. 누락값, 번호 중복, 여러 Parquet 행 그룹도 확인했다.
- 연결 CSV는 Parquet와 변환 기록 확정 후 제거하며 실패하면 완료 처리하지 않도록 확인했다. Parquet의 테스트 정의 메타데이터 중복을 줄였다.
- 전체 측정값 measurements.xlsx를 추가했다. 값·테스트 정의·제목과 행 수, 시트 분할, 출력 제외 설정, 최종 업로드 및 정리 후 보존을 확인했다.
- Report는 전체 측정값 Excel 출력이 켜진 경우에만 해당 링크를 표시한다.
- 자료 증가 시 원본·해시별 실행 검색, 최근 실행과 정리 후보 조회가 전체 DB를 반복 탐색하지 않도록 SQLite 인덱스를 추가했다.
- 실제 로컬 FTP 연결에서 중단 시 완료 목록 미게시, 실패 상태 유지 및 재실행 성공을 확인했다.
- 손상 완료 결과의 새 실행 생성, 손상 선행 단계 차단, 원본 없는 건 정리 보류와 정상 건 정리 지속을 재검증했다.
- 실제 Python 자식 프로세스와 Electron IPC 경계 검증 통과. Chromium에서 1440px·1100px 레이아웃·메뉴·탭·설정 포맷 전달·로그·Report 확인.
- 설치·자동·수동·중지 스크립트, Python/JavaScript 문법, 최신 요구사항·데이터 계약·예시 결과·보관 정책의 일관성을 점검했다.

최종 Python 검증은 25개이며 모두 통과했다. JavaScript 구문, IPC와 화면 검증도 통과했다. 단순히 같은 테스트를 두 번 실행하는 것에 그치지 않고 수정 후 전체 범위를 다시 읽고 추가 요구·오류 경계를 함께 확인했다.

## 남은 운영 확인

실제 Windows Electron 창, 운영 FTP/FTPS 인증서·서버, 최대 양산 STDF 규모, 장기간 서비스 로그·디스크 보존 및 다중 PC 중앙 조정은 현재 데모 환경에서 완료하지 못했다. 부팅 후 자동 시작과 OS 서비스 재시작은 배포 시 구성할 항목이다. 상세 한계는 VALIDATION.md와 README.md에 기록했다.
