# 데모 요구사항 기준 — 2026-10-05

이 문서는 최신 대화에서 확정한 요구사항을 이 데모에 맞게 정리한 기준이다.

1. 프로젝트 문서·화면·답변은 한국어를 사용한다. 기술 식별자와 원본 소스는 기술적으로 필요한 이름을 유지한다.
2. 프로그램 구성요소 폴더는 CODE_xxxx 형식을 사용한다.
3. 파이프라인 자동화 툴은 서버 PC에서 상시 실행하고 사용자 PC에서는 수동 실행할 수 있어야 한다.
4. Electron은 자동화 작업의 설정·실행·운영 이력 화면이다. 결과물 조회·편집 프로그램은 별도 구성이다.
5. 현대적이고 깔끔한 스타일, 좌측 메뉴, 우측 상단 탭별 기능, 우측 하단 본문을 사용한다. 첫 메뉴는 FTP이다.
6. FTP 완료 이력을 확인해 정상 수신 자료는 건너뛰고, 완료되지 않은 자료는 수신한다.
7. 서버 자동 실행과 사용자 수동 실행은 공통 처리 엔진을 사용한다.
8. 전달된 STDF 프로그램을 변환·통계 생성·Report 생성 기능으로 분리한다.
9. 최신 요청에 따라 기본 출력은 가로형 Parquet · ZSTD이다. 기존 CSV는 선택 가능한 호환 포맷으로 유지한다. 실제 사용 테스트 열만 생성하고 테스트 번호 차이는 프로그램 정보·열 식별자와 함께 관리한다.
10. Parquet/CSV는 중간 자료이다. 필요한 데이터를 추출하고 결과물 생성이 완료되면 보관기간에 따라 정리한다. 원본과 필요한 최종 결과물은 보관한다.
11. 히스토그램·맵·YIELD·기본 통계시트와 변환 Report 페이지를 독립 결과물로 생성한다.
12. 코드 작성 금지 요청은 데모 생성 요청으로 이 구현 범위에서 해제되었다. 기존 라이브러리 소스는 보존하고 기능별 어댑터를 새로 만든다.
13. 데모 완료 후 전체 범위를 두 차례 리뷰하고 결과와 수정 사항을 문서화한다.
14. 구현 코드와 최신 문서는 GitHub sk5963/test1 저장소의 CODE_ATLAS_Demo 폴더에 반영한다.
15. 통계·요약 Excel과 별도로 전체 실제 테스트의 가로형 측정값 Excel을 생성하고 최종 결과물로 업로드·보존한다.
16. 개발 Stage 2와 Stage 3은 미정이다. 현재 구현은 Stage 1 파이프라인 데모이다.

기본 300초 자동 간격, 7일 중간 데이터 보관기간, 20개 히스토그램 구간, 단일 로컬 작업공간 및 모의 전송은 변경 가능한 데모 설정이다. 실제 FTP 정보는 제공되지 않았으므로 기본 주소는 ftp.example.invalid로 설정했다. 업로드를 결과물 생성 이후에 두는 이번 데모 순서는 운영 검토에 따라 변경할 수 있다.
