최종 샘플 측정: 원본 2,012,129바이트, 엔진 연결 CSV 849,207바이트, Parquet 452,798바이트. 이 합성 샘플에서 Parquet은 CSV보다 약 46.7% 작다. 전체 측정값 Excel은 589,654바이트이며 최종 보관 파일이다. 작은 합성 파일 측정이며 양산 성능·압축률의 보장이 아니다.

## 미검증 범위

네이티브 Electron 창은 이전 실행 환경에서 종료되었으며 현재 환경은 그래픽 데스크톱이 없어 검증을 완료하지 못했다. 실제 Windows PC, 운영 FTP/FTPS, 최대 양산 파일 성능, 장기간 서비스·로그 보존·디스크 제한, 재시험별 수율 정책, 여러 PC의 중앙 조정은 추가 검증 대상이다. GitHub 자동 검증 결과는 실제 실행 상태를 별도로 확인한다.
